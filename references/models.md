# 型号规格与码值定义

## 尺寸 / 型号对照

| 未出血 (mm) | 出血 (mm) | 型号 | 码位 | 码值范围 |
|---|---|---|---|---|
| 60×90 | 66×96 | p7, p6b, p6, p5, v2, v7c | 10 | 0–1023 |
| 35×80 | 41×86 | p6(小卡), p5(小卡) | 6 | 0–63 |
| 35×80 | 41×86 | p6b(小卡), p7(小卡) | 8 | 0–255 |
| 105×160 | 111×166 | v3 | 10 | 0–1023 |
| 75×105 | 81×111 | s7, v11 | 10 | 0–1023 |

出血 = 未出血上下左右各 +3mm。码值上限 = 2^码位 − 1（10 位=1023，8 位=255，6 位=63）。超上限必须报错终止，不得静默截断。

型号名容错：`catalog_util.resolve_model` 归一化大小写/分隔符/别名（如 `V3`、`v-3`、`p6b小卡`），`--list-models` 列出全部可用型号与模版组。同一尺寸可对应多型号（模版组），按码位/模版几何区分。

出血判定（`catalog_util.size_state`）：源页尺寸与出血/未出血规格比对，容差 0.8mm 内判定为该态；偏差 >3mm 拒绝（不猜）。带裁切框的大版按框居中裁切。交付文件名自动加 `_出血` / `_未出血` 后缀标明状态。

## 黑白码定义

- 黑 = CMYK 0/0/0/100（纯黑），白 = CMYK 0/0/0/0（纯白），**禁止任何色彩转换**
- 码带在页面最上层、贴页底对齐、按模版几何横向排布
- bit=1 画黑条，bit=0 画白条；全部 10/8/6 根都画（白条也占位）

## 位序（实测自 base 模版，存于 catalog.json）

- **常规型号**（p7 组 / s7 / v11 / 小卡）：槽位左→右 = 最高位→最低位
  - 10 位：bit9, bit8, …, bit0；8 位：bit7…bit0；6 位：bit5…bit0
- **V3 特殊**：左→右 = bit9, bit7, bit6, bit5, bit4, bit3, bit2, bit1, bit0, bit8
  （最左槽=bit9，最右槽=bit8，中间 8 槽左→右放实际码值的 bit7…bit0）
- 位序以 catalog.json 的 `slots[].bit` 为准，不要手工假设

## 几何换算（未出血模版 → 目标页）

catalog.json 只存未出血几何（`slots[].x` 相对未出血页左、`bar_h`、`w`，单位 mm）。目标页几何：

```
offset_mm = 3 if 出血 else 0          # 出血版内容相对页左/页底各内缩 3mm
bar_x_pt  = (slot.x + offset_mm) * MM # MM = 72/25.4
bar_w_pt  = slot.w * MM
bar_h_pt  = (tpl.bar_h + offset_mm) * MM
topOff_pt = bar_h_pt                  # 码带贴页底：条顶 = 页底 + bar_h
```

已用 V3/p7/s7/小卡四组双向核对：出血版条高与横移各 +3mm。V3 出血实测 lefts[0]=49.10pt=17.32mm=14.32+3，barH=22.68pt=8mm=5+3，吻合。

## 铺码规则（按卡序 k=(page+1)//2，page 从 1 起）

- **正反不同**（默认 `diff`）：奇数页=2k、偶数页=2k−1（页1=码2、页2=码1……机器识别卡片背面码）
- **正反相同**（`same`）：一张卡两页同码=k（页1,2=1；页3,4=2……）
- **混合**（`diff:1-40,same:41-100`）：按卡序分段，段内连续编号
- 起始码 `--start N`：默认 1；diff 规则下首卡正面码=N+1、背面=N

## 输出要求

1. PDF 输入 → 只输出 PDF；AI 输入 → 输出 .ai + 转曲 PDF
2. 源文件上的标尺线、定位线、裁切线、**黑色裁切框**全部去除
3. 源尺寸与要求不符时，按更接近的一侧（出血/未出血）裁切后再铺码
4. 铺码在所有其他处理之后（码在最上层、独立成块）
5. 交付前逐页解码校验 mismatch=0，残留大描边对象=0
